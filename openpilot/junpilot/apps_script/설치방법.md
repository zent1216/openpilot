# 준파일럿 구글 드라이브 수신기 설치

콤마4가 주행 기록을 내 구글 드라이브에 올릴 수 있게 하는 작은 프로그램이다. 한 번만 설치하면 된다.

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 모두 지우고 `Code.gs` 내용을 붙여넣기
3. `SECRET` 값을 아무도 모를 긴 문자열로 바꾸기 (예: 영문+숫자 30자)
4. 저장(💾) → 오른쪽 위 **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** → 권한 허용 (내 계정 선택 → 고급 → 안전하지 않음으로 이동 → 허용)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
7. 준파일럿 관리 페이지 → **연결** 탭 → URL과 SECRET 입력 → 저장

저장 위치: 내 드라이브 › `준파일럿 로그` › `날짜_주행이름` 폴더

- 주소를 아는 사람도 SECRET 없이는 아무것도 올릴 수 없다.
- 코드를 고치면 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다.
