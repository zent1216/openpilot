# 준파일럿 (junpilot)

콤마4 + 기아 PV5용 오픈파일럿. 공식 마스터에 OPKR·당근파일럿의 좋은 점을 더했어요.

설치 주소: `installer.comma.ai/zent1216/junpilot`

## 주소
| 페이지 | 주소 | 용도 |
|---|---|---|
| 관리 페이지 | `http://<장치 IP>:8082` | 상태, 주행기록 보내기, 설정 |
| 복구 페이지 | `http://<장치 IP>:8083` | 켜지지 않을 때 되돌리기, 다시 받기, 재부팅 |

콤마4 핫스팟에 연결했다면 장치 IP는 `192.168.43.1` 이에요.

## 기능
- **PV5 지원**: 차종은 `KIA_PV5`로 고정돼 있어요 (`/data/junpilot_car` 파일로 변경, `auto`면 자동 인식)
- **콤마 서버 통신 차단**: 업로드, 원격 연결, 서버 등록 모두 꺼짐
- **크루즈 속도 자동 조절** (관리 페이지에서 켜야 동작, 기본 꺼짐)
  - 순정 스마트크루즈의 설정속도만 RES+/SET- 버튼 신호로 바꿔요. 가감속과 긴급제동은 순정 그대로예요.
  - 커브 감속: 카메라가 본 앞 커브에 맞춰 미리 설정속도를 낮춰요.
  - 단속카메라·구간단속 감속: 차량 순정 내비의 단속 정보를 사용해요.
  - 주행 모드: 부드럽게 / 보통 / 빠르게
  - 핸들 버튼으로 바꾼 속도를 기억하고, 자동으로 낮춘 뒤에는 그 속도로 돌아가요.
  - 버튼 신호가 무시되면 간격을 늘리고, 계속 무시되면 10초 쉬었다가 다시 시도해요.
- **복구 서버**: 2분 이상 정상 동작한 버전을 자동 기록하고, 그 버전으로 되돌릴 수 있어요.

## 안전 관련 변경
- 판다 안전 코드는 한 곳만 바꿨어요: 크루즈가 켜져 있고 제어가 허용된 상태에서 SET-(속도 내리기) 버튼 허용.
- 조향 토크 한계, 운전자 감시 기능은 공식 그대로예요.

## 실차 확인이 필요한 것
- PV5 크루즈 버튼 메시지 종류 (일반형 0x1CF인지 0x1AA인지). 0x1AA면 버튼 제어가 동작하지 않아요.
- 버튼 한 번에 보내는 메시지 수와 간격
- 내비 단속 신호가 A-CAN/E-CAN에서 실제로 보이는지
- PV5 펌웨어 값 (자동 인식용)
